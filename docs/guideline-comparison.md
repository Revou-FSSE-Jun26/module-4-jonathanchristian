# Guideline Comparison: Before and After

Compares the number of guideline violations in AI-generated output produced **without** the guidelines against the same output produced **with** them (Requirement 30.4). The "after" count must be lower. This document is filled in task 23.2.

## How the "without guidelines" sample is produced

1. Pick one self-contained feature (for example the comments Blueprint_Package, or the `BoardList` component).
2. In a fresh AI session, give it only the feature's requirement text and no `guidelines/` files. Save the output unchanged as the "before" sample.
3. In another fresh session, give it the same requirement text plus the matching guideline files. Save the output as the "after" sample.
4. Count the guideline entries (G-BE, G-DB, G-FE ids) each sample violates, using the checklist at the end of each guideline file.
